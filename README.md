# OpenLobby Homebrew Tap

Install the OpenLobby agent:

```bash
brew install openlobby-gg/tap/lobby
lobby
```

Or tap explicitly:

```bash
brew tap openlobby-gg/tap
brew install lobby
```

Binaries are served from `https://downloads.openlobby.gg` (not built from source). Formulae in this tap are updated by the OpenLobby release workflow.
